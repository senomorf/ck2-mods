# UI test (charters, v0.1 step 2): as King Harold II of England, hire ships from King Svend II of
# Denmark through Svend's diplomacy menu, as a player would, pick 50 galleys, and wait for Svend's
# answer. Coordinates were read off the live test box's screenshots (1280x720; Hire Ships sits
# below Ask for Ships). Run it on the box from vanilla's 1067.1.1 save (docs/test-pipeline.md,
# "UI tests"), with the request_ships setup, which gives Harold 100 gold:
#   tools/box-run.sh env CAMPAIGN_PROBE_SAVE=.box/start.ck2 CAMPAIGN_PROBE_MOD=allied_fleets \
#     CAMPAIGN_PROBE_TESTS=no CAMPAIGN_PROBE_EFFECTS=tests/game/allied_fleets/ui/request_ships_effects.txt \
#     tools/campaign.sh --steps tests/game/allied_fleets/ui/hire_ships.txt
launch -startgame -start_save=%SAVE%
until 300 Launching SINGLEPLAYER-game
wait 25                 # at 10 s, a freshly started box lost the console key (twice, 2026-11-15)
focus
key grave              # the console
wait 3
type run ck2test_effects.txt
key Return
wait 3
until 10 uitest: King Svend II of Denmark \(101515\) allied with
type play 122          # play Harold
key Return
wait 3
type hello 101515      # open Svend's character screen
key Return
wait 3
key grave
wait 5
rclick 150 190         # Svend's portrait: the diplomacy menu
wait 3
move 338 293           # Hire Ships; its tooltip lists the requirements
wait 4
shot menu
click 338 293          # the decision's window
wait 4
shot window
move 606 500           # the acceptance ("Yes", "Maybe" or "No", v0.2): its tooltip lists the lender's score and reasons
wait 3
shot acceptance
click 606 524          # Do it!
until 20 CK2TEST took afl_hire_ships root=101515 from=122
wait 3
shot counts            # Harold's choice of count (afl.40): Svend's own ports spare about 58, so only 50 is offered
click 650 529          # the first option: 50 galleys
until 20 afl: (charter fleet of 50 galleys ready in|refused by)
wait 3
shot answer            # Svend signs (afl.44: the ships wait off his port) or refuses (afl.13), as the AI chances fall
